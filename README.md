# Portfolio-optimization

This repository contains the code for the Portfolio Management Course project at Imperial College. In this project, we analyse and replicate the paper DeMiguel, Victor and Garlappi, Lorenzo and Uppal, Raman, Optimal Versus Naive Diversification: How Inefficient is the 1/N Portfolio Strategy? (May 2009). The Review of Financial Studies, Vol. 22, Issue 5, pp. 1915-1953, 2009, hhm075[hhm075], Available at SSRN: https://ssrn.com/abstract=1376199 or http://dx.doi.org/hhm075.
